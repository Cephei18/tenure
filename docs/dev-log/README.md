# Development log

journal (`PROGRESS.md`), the blocker log (`BLOCKERS.md`) and the loop's operating notes (`START_HERE.md`). They
are kept unedited as a historical record, so their paths and commands are as written at the time, relative to the
repo root (where these files used to live).
